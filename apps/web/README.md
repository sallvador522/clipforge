# apps/web — Next.js Frontend (Milestone 5, not yet implemented)

Stack: Next.js, React, TypeScript, Tailwind CSS, customised shadcn/ui primitives, Motion for React. Design rules and composition are defined in `docs/DESIGN_SYSTEM.md` (dark charcoal, warm type, signal orange, Manrope + IBM Plex Mono, video-preview-first, voice as the main visual element). No frontend code, dependencies, or build exist yet by design; the foundation milestones are backend/pipeline-first. Before implementing, load the `frontend-design`, `web-design-guidelines`, and `motion` skills, and verify in a real browser.
