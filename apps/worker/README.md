# apps/worker — Python Worker

Implemented: `clipforge_worker/masks.py` (ADR-005 mask writer/loader/validation), `clipforge_worker/fixtures.py` (deterministic synthetic fixtures, ADR-007), `clipforge_worker/processor.py` (mock pipeline per job: transcribe → plan → segment → optional background; clarification completes without segmentation; failures recorded with originals preserved), `clipforge_worker/worker_process.py` (persistent polling worker).

Run the worker as its own process: `python -m clipforge_worker.worker_process --storage storage --poll 0.5`. It claims ready jobs atomically (one worker per job), processes sequentially on CPU, and logs to `clipforge.worker`. Pipeline: transcribe → plan → segment → (background) → render → verify. `clipforge_worker/renderer.py` is the real FFmpeg + OpenCV engine (Milestone 4): bounded-memory streaming, feathered alpha, blur/replacement, original audio preserved, output ffprobe-verified before `render_status="verified"`. Clarification/unsupported jobs render nothing and keep `render_status="not_implemented"`. No PyTorch, CUDA, local SAM, or MediaBunny.
